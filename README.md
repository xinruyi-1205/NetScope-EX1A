# NetScope-EX1A：网络嗅探器与协议分析系统

本项目是中国科学院大学《软件与系统安全》课程实验 1A——带 GUI 的网络嗅探器设计与实现。

本项目基于 Python 开发，利用 Tkinter 构建图形用户界面，通过 Windows Npcap 抓包接口实现实时网络数据包捕获，并提供多种网络协议的解析、过滤和统计功能。

## 二、主要功能

1. **实时网络抓包**：支持选择本机网络接口，开始和停止捕获网络数据包。
2. **协议识别与解析**：支持 Ethernet、IPv4、IPv6、TCP、UDP、ICMP、DNS 等协议的识别和部分字段解析。
3. **BPF 协议过滤**：支持 TCP、UDP、ICMP、DNS 等捕获过滤条件。
4. **数据包详细查看**：展示源地址、目的地址、端口、协议、报文长度及十六进制原始数据。
5. **TCP 双向流统计**：按通信双方 IP 地址和端口对 TCP 数据包进行分组，并统计数据包数量、捕获字节数及时间范围。
6. **PCAP 文件操作**：支持保存捕获的数据包，以及重新读取 PCAP 文件。
7. **CSV 导出**：支持将数据包信息导出为 CSV 文件，便于后续分析。

## 三、运行环境

- 操作系统：Windows 10/11（64 位）
- Python：3.10 或以上版本
- 图形界面：Tkinter
- 抓包驱动：Npcap
- 开发语言：Python

## 四、运行方法

### 1. 安装 Python

从 Python 官网下载安装 Python 3.10 或以上版本。

https://www.python.org/

通过命令检查安装情况：

```cmd
python --version
```

### 2. 安装 Npcap

从官方网站下载并安装 Npcap：

https://npcap.com/

### 3. 启动程序

进入项目源码目录，执行：

```cmd
python main.py
```

也可以尝试运行提供的 Windows 启动脚本。

### 4. 开始抓包

1. 在界面顶部选择当前使用的 Wi-Fi 或以太网网卡。
2. 点击“开始抓包”。
3. 使用浏览器访问网页，产生网络流量。
4. 在数据包列表中查看捕获结果。
5. 点击某一条数据包，查看协议字段和十六进制数据。

请仅在本人设备或已获授权的网络环境中进行抓包。

## 六、项目局限性

本项目主要面向课程实验和网络协议学习，不以替代 Wireshark 等成熟协议分析工具为目标。

对于 HTTPS/TLS 加密通信，程序可以识别部分协议特征，但不会直接解密加密的应用层数据。
